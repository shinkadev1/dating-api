# 58040 — вторая ежедневная рассылка (Давай → чат, Премиум)

Режим: plan. Статус: ждёт ответа пользователя, код не менялся.

## Как сейчас (проверено по master)
- Chat API: BroadcastService._send_daily, settings DAILY_PROMO_* (окно 19–21 МСК, экран daily_promo).
- БД: daily_promos (PK day) и daily_promo_log (PK day+user) — одна рассылка на день, второй слот схема не допускает.
- Боты TG/VK: экран daily_promo в flow/flow.yaml; _deliver_notice показывает любой screen из notice — код ботов менять не нужно.

## План
1. dating-api: миграция 012_daily_promo_slots.sql — колонка slot ('evening' по умолчанию для старых строк), PK (day, slot) в обеих таблицах.
2. settings: список слотов DAILY_PROMOS = [evening: 19–21, daily_promo; new: <окно>, daily_promo_2, текст].
3. service/_send_daily и repositories/daily_promo.py: цикл по слотам, slot в ensure_day/claim/log.
4. Тесты test_daily_promo_db.py: два слота в день, один человек получает оба, дубли внутри слота исключены, старые строки = evening.
5. dating-bot-tg и dating-bot-vk: экран daily_promo_2 в flow.yaml: текст со скриншота, «Давай» (action find → chat), «💎 Премиум» (action premium).
6. Порядок выкладки: боты (экран) → dating-api (рассылка). Включается с даты деплоя; если окно на сегодня уже прошло — первая отправка завтра.

## Риски
- Миграция меняет PK на боевой таблице (данные сохраняются, но проверить на копии).
- Два промо в день — больше отписок/блокировок бота.

## Нужно от пользователя
- Текст сообщения и картинка со скриншота (скриншот до агента не дошёл).
- Время отправки (например 12–14 МСК).
