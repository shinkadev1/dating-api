# Задача 59046 — вторая ежедневная рассылка «Привет»

Одобренный план: одна вечерняя рассылка (случайный момент 19:00–21:00 МСК), экран чередуется по дням МСК одинаково для всех: 14.11.2026 и далее через день — новый `daily_hello` («Давай начнем с простого «Привет» и посмотрим, куда это нас приведет ☕✨», кнопки «Давай» → поиск, «💎 Премиум» → премиум), в остальные дни — прежний `daily_promo`. Вторая кнопка — «💎 Премиум» (по задаче, не «Открыть профиль» со скриншота-образца).
