# Dating / Chat API

Проверено по локальным исходникам: **2026-10-31**. Пути в этом комплекте относительны корню репозитория.

Центральный сервис анонимного чата: общая очередь, пары, события, медиа, посетители и статистика. Включает мост к внешним собеседникам.

Стек: Python, FastAPI, Postgres, Redis, S3; отдельный Python-сервис engine_bridge.

## Порядок чтения

1. Локальный `AGENTS.md`, этот файл, [CURRENT_TASK.md](CURRENT_TASK.md), [STATE.md](STATE.md).
2. [CONVENTIONS.md](CONVENTIONS.md) и [ARCHITECTURE.md](ARCHITECTURE.md) для нужной области.
3. Релевантные исходники; [CHANGELOG.md](CHANGELOG.md) — если нужна история.

Этот комплект самодостаточен для работы в отдельном checkout. Общий `../.ai/`, если есть, описывает остальные сервисы. Не хранить здесь копию всей общей архитектуры. При расхождении описания поведения с кодом проверять код и обновлять память; инструкции пользователя и применимые AGENTS сохраняют силу.

Локальные документы можно версионировать вместе с репозиторием; в этой задаче коммиты не создавались. Состояние production не установлено чтением исходников.
