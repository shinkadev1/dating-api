# Страница оплаты: заметки к развёртыванию

Запуск: `docker compose -f docker-compose.yml -f docker-compose.payments.yml --profile payments up -d --build` из корня репозитория. Переменные перечислены в `.env.example`. `PREMIUM_LINK_SECRET` должен совпадать у chat-api и premium_site.

## IP клиента за прокси

1. Укажите в `PREMIUM_FORWARDED_ALLOW_IPS` адрес прокси, как его видит контейнер: обычно это шлюз сети Docker (`docker network inspect <сеть>`, поле Gateway) или адрес контейнера туннеля. По умолчанию стоит `127.0.0.1`, то есть заголовкам никто не доверяет. Значение `*` не используйте.
2. Прокси должен перезаписывать `X-Forwarded-For` адресом клиента, а не дописывать к нему. Для nginx: `proxy_set_header X-Forwarded-For $remote_addr;`. За Cloudflare прокси подставляет туда настоящий IP из `CF-Connecting-IP`.
3. `YOOKASSA_WEBHOOK_IPS` включайте только после шагов 1–2, иначе все уведомления придут с адреса прокси и будут отклонены. Адреса берите из документации ЮKassa.

## Ссылка из чата

Боты получают адрес через `GET /api/v1/peers/{platform}/{bot_key}/{user_id}/premium/link` и отправляют его кнопкой клавиатуры (URL-кнопка), а не текстом. Так меньше превью и пересылок. Ссылка живёт 24 часа и входит один раз. Открытие по GET (в том числе превью мессенджера) только показывает страницу «Продолжить», а вход происходит по нажатию.
